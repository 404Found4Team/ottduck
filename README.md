# ottduck (OTT덕후)

OTT 콘텐츠에 대한 리뷰와 소통(게시판·댓글·실시간 채팅)을 중심으로, 퀴즈 미니게임을 통해 포인트를 적립하고
이를 활동 혜택(게시글 하이라이트, 경고 차감)으로 소비하는 **포인트 생태계 기반 커뮤니티 서비스**입니다.

**서비스 목적**

1. 파편화된 OTT 플랫폼(넷플릭스·티빙·디즈니플러스 등)별 감상평을 한 곳에 모아 정보 탐색 비용을 절감한다.
2. 실시간 채팅과 퀴즈 미니게임을 통해 커뮤니티의 자발적 참여와 체류율을 높인다.
3. 등급·포인트 제도를 통해 지속적인 참여를 유도하고, 비속어 필터·신고·경고 제도로 건전한 커뮤니티 환경을 조성한다.

> 공통 필수 원칙: 모든 게시글·댓글·실시간 채팅 메시지에 **비속어 필터링 시스템**을 일괄 적용한다.

자세한 기획 배경은 [docs/project-plan.md](docs/project-plan.md), DB 구조는 [docs/database-schema.md](docs/database-schema.md)를 참고하세요.

## 타겟 유저 및 기대효과

| 구분 | 특징 |
| --- | --- |
| 1차 타겟 | 다수의 OTT(넷플릭스·디즈니플러스·티빙·웨이브 등)를 구독 중이고, 콘텐츠 선택을 위해 리뷰를 참고하는 20대~30대 이용자 |
| 2차 타겟 | 다른 이용자와 실시간으로 소감을 나누고 싶은 커뮤니티 참여형 이용자 |
| 3차 타겟 | 게임·퀴즈 요소를 통해 재미를 느끼며 서비스에 머물러 있고 싶은 이용자 |

- 파편된 OTT 정보 탐색 비용 절감 → 이용자 체류시간 증가
- 퀴즈·포인트 제도를 통한 재방문율(리텐션) 확보
- 비속어 필터·신고·경고 제도로 논란이 적고 건전한 커뮤니티 형성

## 기술 스택

| 분류 | 기술 |
| --- | --- |
| 백엔드 | Java 21, Spring Boot 4, MyBatis |
| 화면 | Thymeleaf, HTML/CSS/JS |
| 실시간 통신 | WebSocket (STOMP over SockJS) |
| 데이터베이스 | MySQL |
| 비동기 통신 | fetch API (중복확인, 댓글 등록·삭제 등) |
| 빌드 | Gradle |

## 메뉴 구조 (IA)

```
[메인페이지] /
├─ 헤더 통합검색 → 게시글 목록 /review/list?keyword=
├─ 카테고리 네비게이션 (전체·넷플릭스·티빙·디즈니플러스·기타·하이라이트·공지사항·Q&A)
│    └─ 게시글 목록 /review/list → 게시글 상세 /review/{reviewId}
├─ 인기 리뷰(플랫폼별 top5) → 게시글 상세
├─ 공지사항 /notice → 공지 상세, Q&A 탭(상세/작성/수정)
├─ 로그인 /login (일반·카카오·구글)
├─ 회원가입 /join (아이디·이메일 중복확인 AJAX, 취향 장르 선택)
├─ 마이페이지 /mypage (내 정보, 내 리뷰, 북마크, 포인트 내역/상점, 등업·탈퇴 신청)
├─ 🔔 알림 패널 (헤더 공통, 로그인 필요)
├─ 💬 채팅 패널 (헤더 공통, WebSocket, 로그인 필요) — 목록/채팅/개설 탭
├─ 💡 퀴즈 패널 (헤더 공통, 로그인 필요) — 하루 3회 제한
└─ 관리자 페이지 /admin (회원·신고·Q&A·공지·배너·금칙어 관리, KPI 대시보드)
```

## 주요 정책

### 회원 등급

| 등급 | 명칭 | 조건 | 주요 권한 |
| --- | --- | --- | --- |
| Lv.0 | 구경꾼 (비회원) | 미가입 | 게시글 조회만 가능 |
| Lv.1 | 일반회원 (시청자) | 회원가입 완료 | 게시글·댓글 작성, 채팅 참여, 포인트 적립 |
| Lv.2 | 고급회원 (평론가) | 게시글 작성 3회 · 유효 경고 0회 · 게시글 좋아요 총합 100회 이상 | 채팅방 개설/관리 |
| Lv.99 | 관리자 | 운영진 지정 | 전체 관리 권한 |

등업 신청은 신청 접수 후 관리자가 승인/반려하는 수동 심사 방식입니다.

### 경고 및 제재

| 단계 | 조건 | 조치 |
| --- | --- | --- |
| 1차 | 경고 1회 누적 | 경고 1회 누적 표시 |
| 2차 | 경고 2회 누적 | 경고 2회 누적 표시 |
| 3차 | 경고 3회 누적 | 계정 강제정지(탈퇴 처리) |
| 구제 | 포인트 10,000pt 소진 | 경고 1건 차감(단, 이미 강제정지된 계정은 불가) |

회원가입 시 비속어·도배·스팸 등 이용규칙 위반 시 경고가 부여될 수 있으며, 경고 3회 누적 시 계정이 정지될 수 있다는 내용에 동의해야 가입이 완료됩니다.
